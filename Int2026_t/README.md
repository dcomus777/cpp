# Лабораторная работа 2

## Задача

  Реализовать пользовательский тип для целого знакового числа фиксированной длины **int2026_t**.
  Число содержит 2026 значащих бит, включая знаковый.
  Размер получившегося типа не должен превышать 254 байта.
  Неиспользуемые биты хранения не расширяют диапазон значений.
  Диапазон значений: $[-2^{2025},\ 2^{2025} - 1]$

  Для вышеуказанного типа требуется реализовать следующий набор функций и операторов:

     1. Конвертация из типа int32_t
     2. Конвертация из строки
     3. Сложение
     4. Вычитание
     5. Умножение
     6. Деление
     7. Операторы сравнения `==` и `!=`
     8. Вывод числа в поток (необязательно в десятичной системе счисления)

### Правила операций

- `from_int(int32_t)` сохраняет значение исходного числа, включая `INT32_MIN` и `INT32_MAX`.
- `from_string(const char*)` принимает десятичную строку формата `[+-]?[0-9]+`:
  необязательный знак и хотя бы одну цифру. Ведущие нули разрешены;
  `"0"`, `"-0"` и `"+0"` обозначают одно и то же число.
- Числа вне диапазона при конвертации из строки обрабатываются по правилу переполнения ниже.
- Деление целочисленное, с округлением к нулю: `-7 / 3 == -2`, `7 / -3 == -2`.
  При `MIN / -1` результат равен `MIN` по правилу переполнения.
- Деление на ноль, некорректные строки и `nullptr` не входят в обязательный контракт и не проверяются тестами.
- `operator<<` выводит представление значения в выбранной вами системе счисления и возвращает
  переданный поток, чтобы работали цепочки `stream << a << " " << b`.
  Вывод в десятичной системе не обязателен; выбранный формат должен различать разные значения.

## Переполнение

В отличие от стандарта, где переполнение знаковых целых чисел является UB, мы просим вас реализовать поведение
`wrap around` (циклический переход). Здесь `MIN = -2^2025`, `MAX = 2^2025 - 1`.
Результат приводится по модулю `2^2026` к диапазону $[-2^{2025},\ 2^{2025} - 1]$.
Это правило действует для конвертации из строки, сложения, вычитания, умножения и деления.
Например, `MAX + 1 == MIN`, `MIN - 1 == MAX`, `MIN * 2 == 0`, `MIN / -1 == MIN`.
